---
title: "Create a Tweet or Reply"
openapi: POST /twitter/tweets/create
description: "Posts a new tweet. To create a reply, provide the `reply_tweet_id`. This endpoint does not handle quote tweets,$0.001 per call."
---

<Warning>
This route needs a Twitter cookie or `auth_token` in addition to the TwexAPI API key.
Never send an X password or 2FA code.
</Warning>
